# Amethys Launcher v0.2.0

**Published:** 23 November 2026  
**Release:** [GitHub release v0.2.0](https://github.com/Likounsee/Amethys-Launcher/releases/tag/v0.2.0)  
**Source tag:** `v0.2.0`  
**Release commit:** `2afd9dd0484ef5a3377ac6f695f4d8c413962a33`

Amethys Launcher 0.2.0 is the first published desktop preview of the project. It adds a graphical game-library experience on top of the existing Rust Core and IPC architecture. It remains experimental software: it is not a finished launcher and is not recommended as a production replacement for official platform clients.

## Highlights

- Graphical local game library connected to Amethys Core over the versioned IPC protocol.
- Search, platform filters, sorting and game details.
- Executable-path configuration and launching of configured local games.
- Supported launcher discovery and explicit import into the local library.
- Custom game covers, including reset to the generated default cover.
- Responsive desktop layout, keyboard navigation and visible loading, confirmation, error and notification states.
- Background library loading, refresh, imports and local library updates.

The catalogue/store screen is not a connected commercial store in 0.2.0. Prices, promotions, purchases, licences and downloads are not provided. Do not interpret placeholders or future-facing screens as available services.

## Installation and first launch

1. Download the archive for your operating system from the release page.
2. Extract it to a directory where your user account has read/write access.
3. Start the graphical application:
   - **Windows:** run `amethys-launcher.exe`.
   - **Linux:** run `./amethys-launcher`. If the executable bit was not preserved by the extraction tool, run `chmod +x amethys-launcher` first.
4. The application uses the local Amethys Core agent and IPC. The packaged read-me describes the included binaries; the CLI is available as `amethysctl.exe` on Windows or `./amethysctl` on Linux.
5. Run `amethysctl --help` (or `./amethysctl --help`) to inspect the available CLI commands.

Keep official platform launchers as the source of truth for game installation, updates, accounts, authentication and licences. Amethys does not bypass DRM or platform restrictions.

## Validation and known limitations

The release workflow completed successfully on 23 November 2026. Both platform jobs passed release tests, desktop Clippy, desktop tests, release builds, archive staging and archive smoke checks. The publish job generated and verified the combined SHA-256 manifest and uploaded both archives.

- **Windows:** release archive contents and packaged CLI/agent smoke checks passed in CI. A separate Windows desktop development package had previously passed 15 manual checks on a real Windows machine; that manual result does not claim that every PC or game is compatible.
- **Linux:** release archive contents and packaged CLI/agent smoke checks passed in CI. Manual testing on a physical Linux machine has not yet been completed.
- **macOS:** not supported by this release.

Automated tests and packaging checks do not prove compatibility with every launcher version, game, GPU, desktop environment or machine. Discovery coverage remains adapter-specific; see [launcher discovery coverage](../discovery/LAUNCHER-COVERAGE.md).

## Important limitations

- Experimental preview; not production-ready.
- No connected commercial store, purchases, account system, game downloads or game installation.
- No cloud saves, cloud synchronization or automatic updater.
- Launcher discovery is limited to implemented metadata adapters and may not detect every installation.
- A detected game is not guaranteed to launch; executable configuration and platform requirements still apply.
- Linux has CI validation but still needs real-machine testing.
- The archives are portable packages, not system installers or background services.
