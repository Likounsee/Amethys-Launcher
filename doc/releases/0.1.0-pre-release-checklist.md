## Scope and known limitations

- [x] The release notes identify this as the first small public test milestone.
- [x] The documentation states that the project is unfinished, experimental and not recommended for everyday or production use.
- [x] The CLI-only nature and absence of a graphical interface are documented.
- [x] Missing store/catalogue, downloads/installations, accounts, cloud saves, backups and automatic updates are documented.
- [x] Launcher-specific real-install evidence and pending tests are documented separately in [launcher discovery coverage](../discovery/LAUNCHER-COVERAGE.md).
- [x] macOS remains outside the 0.1.0 test target.

## Remaining work after release

Publication and automated packaging are complete. This does **not** mean the application itself is complete or fully validated. Continue with real-world Windows/Linux testing, bug fixes, core hardening, launcher compatibility work and planning for later milestones. Do not describe future features as available in 0.1.0.

**Release result:** the first 0.1.0 packages were successfully built and published. The release remains an experimental test version, not a finished launcher.
