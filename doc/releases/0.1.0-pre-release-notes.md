# Amethys Launcher 0.1.0 pre-release — draft notes

> Status: preparation document only. No release has been tagged, built, or published.
> Proposed first candidate tag: `v0.1.0-pre.1`.

## What this candidate is

Amethys Launcher 0.1 is an early, portable Windows/Linux foundation for discovering locally installed PC games, importing selected detections into a local library, checking saved installation paths, and launching a game through an explicitly configured executable.

This is a **pre-release** intended for cautious evaluation and feedback. It is not a finished graphical launcher and does not replace the official launchers.

## Included

- Rust-based Amethys agent and `amethysctl` command-line client.
- Local IPC between the CLI and agent:
  - Windows named pipes with a restricted user/System ACL.
  - Linux Unix-domain sockets with user-only permissions.
- Local SQLite-backed game library and configuration.
- Read-only discovery from supported launcher metadata:
  - Steam;
  - Epic Games Launcher on Windows;
  - Heroic / Legendary;
  - GOG Galaxy;
  - Amazon Games;
  - EA app on Windows;
  - Ubisoft Connect on Windows;
  - Battle.net on Windows;
  - Riot Games on Windows;
  - initial Xbox GDK detection on Windows.
- Explicit single-game and bulk import; discovery does not silently modify the Amethys library.
- Library listing, platform filtering, local search and removal.
- Read-only installation/executable verification.
- Safe launch of a configured executable without invoking a shell, constrained to the registered installation directory.
- Windows and Linux build/test CI and portable archive packaging.
- SHA-256 checksums for release archives.

The agent currently runs in the foreground. Start it in one terminal before using the CLI in another. See [the first-run guide](../technical/RELEASES.md#first-run-notes).

## Known limitations and testing status

- This candidate is a CLI/core release; there is no graphical interface.
- The archives are portable binaries, not installers. There is no service registration, autostart, desktop shortcut, updater or uninstaller.
- There is no game download/install, online store/catalogue, account system, cloud save synchronization or backup feature.
- Discovery is metadata-based and read-only. It does not verify game-file integrity or guarantee that a detected game can launch.
- Real-install validation is not uniform across adapters. Consult [launcher discovery coverage](../discovery/LAUNCHER-COVERAGE.md) and preserve its per-adapter status:
  - Steam and Epic have local Windows real-install checks recorded.
  - EA app has a local Apex Legends/custom-library check recorded.
  - VALORANT has a local Riot installation check recorded; other Riot titles remain pending.
  - Battle.net has fixture/CI coverage but no recorded real-install validation.
  - Xbox GDK detection remains initial and requires real GDK installation validation.
  - Linux Steam discovery has fixture/CI coverage; real-machine validation remains pending.
  - Other adapters may be fixture-tested only; see the coverage table rather than assuming real-install support.
- macOS is not a 0.1 release target.
- The Windows and Linux CI results demonstrate automated build/test and archive smoke-test coverage, not universal hardware or launcher compatibility.

## Security and privacy

Amethys does not bypass DRM, licensing, authentication, anti-cheat or platform restrictions. Discovery reads launcher metadata and does not modify game installations or launcher databases. IPC is local-only and must not be exposed over a network.

Do not send credentials, tokens, private launcher databases, personal paths or other sensitive diagnostics in public feedback. Redact usernames and private directory names from logs.

## Feedback

Report reproducible bugs and compatibility observations through GitHub Issues, following the repository templates. Include operating system, launcher/version when known, exact Amethys command, expected/actual behaviour and sanitized output. Do not attach credentials or private platform data.

## Disclaimer

This is pre-release software. Back up important data as a general precaution. The application is designed to manage its own local library and to read launcher metadata; nevertheless, use it cautiously and report unexpected behaviour. Official launchers remain responsible for installing, updating, authenticating and licensing games.
