# Desktop UI previews

These PNG files are historical visual previews of the Amethys Launcher desktop interface. They are retained for design reference and documentation only; they are not loaded by the application at runtime.

The maintained implementation lives in `prototypes/ghostengine-amethys-preview/` and uses the single vendored GhostEngine snapshot in `vendor/ghostengine/`. Do not copy these images or the former UI source snapshot over the maintained source tree.
